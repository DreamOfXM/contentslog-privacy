# Contents Log — support and privacy

Public pages for **Contents Log: Home Inventory** (iOS).

- [Support](support.html) — how to restore the unlock, get your data out, and what the photo messages mean.
- [Privacy](privacy.html) — what the app collects: nothing.

The app stores rooms, items, values and photos in its own storage on the iPhone. There is no account and no
server, so there is no backend for anyone to read.
